# KMITL Canteen — Demo พร้อมใช้งาน

**สำหรับ Windows 64-bit ไม่ต้องติดตั้ง Python**

## ดาวน์โหลด

[ดาวน์โหลด Demo_002_Windows.zip](https://github.com/69030099-Thanapon/KMITL_Canteen/raw/refs/heads/main/Demo/Demo_002_Windows.zip)

ไฟล์ประมาณ 36 MB หากเปิดหน้ารายการไฟล์ ZIP ใน GitHub ให้กด Download raw file

## เปิดแอป

1. ดาวน์โหลด ZIP แล้วคลิกขวา > Extract All / แยกทั้งหมด
2. เปิดโฟลเดอร์ `Demo_002` ที่แตกไฟล์แล้ว
3. ดับเบิลคลิก `Demo_002.exe` จะเปิดหน้าลูกค้าและร้านค้าคู่กัน
4. เก็บ `_internal` และ `Database SQLite` ไว้ข้าง exe เสมอ ห้ามคัดลอกเฉพาะ exe
5. วางโฟลเดอร์ในตำแหน่งที่เขียนข้อมูลได้ เช่น Documents

## บัญชีสำหรับสาธิตเท่านั้น

| ฝั่ง | ชื่อผู้ใช้ | รหัสผ่าน |
|---|---|---|
| ลูกค้า | demo_customer | Demo12345 |
| ร้านครัวสิริ | demo_shop | Demo12345 |

บัญชีและรหัสผ่านนี้สร้างไว้สำหรับเดโมสาธารณะ ไม่ใช่บัญชีผู้ใช้งานจริง

## ลองสั่งอาหาร

เลือกคณะครุศาสตร์ > ร้านครัวสิริ > เมนูและตัวเลือก > ตะกร้า > ข้อมูลผู้รับและเวลารับในอนาคต > แจ้งชำระจำลอง

สลับไปหน้าร้าน รอรายการอัปเดตประมาณ 3 วินาที แล้วกดยืนยันเงิน > เริ่มเตรียม > พร้อมรับ > รับแล้ว ดูสถานะฝั่งลูกค้าควบคู่กัน

ลองสั่งอีกออเดอร์แล้วยกเลิกก่อนร้านยืนยันเงิน หลังยืนยันแล้วลูกค้าจะยกเลิกไม่ได้

## ข้อมูลและข้อจำกัด

- ไม่ต้องโอนเงินจริง ใช้ QR จำลอง ไม่เชื่อมธนาคาร
- ชุดดาวน์โหลดเริ่มต้นไม่มีออเดอร์หรือบัญชีลูกค้าจริง
- ออเดอร์ซ้อมจะเก็บใน `Database SQLite/canteen.db` ของชุดนี้ ปิดแล้วเปิดใหม่ข้อมูลยังอยู่
- ลูกค้าและร้านค้าใช้ฐานข้อมูลเดียวกันบนคอมพิวเตอร์เครื่องเดียว ยังไม่เชื่อมออเดอร์ข้ามเครื่อง
- ทดสอบการเปิดหน้าลูกค้าและร้านค้าบน Windows ของผู้พัฒนาแล้ว ยังไม่ได้ทดสอบทุกเครื่องหรือทุก Windows version
- ชุดนี้เป็นสำเนาสำหรับสาธิตวันที่ 10 พฤศจิกายน 2569 ไม่อัปเดตตามโค้ดใน repository โดยอัตโนมัติ
- `SHA256.txt` ใช้ตรวจสอบว่าไฟล์ดาวน์โหลดตรงกับต้นฉบับ

ชุด Demo นี้แพ็กจากงาน UI สำหรับสาธิต การวางไฟล์ดาวน์โหลดบน main ไม่ได้รวมการเปลี่ยนแปลงซอร์สโค้ดจาก branch ui เข้า main

## ใหม่ใน Demo_002
