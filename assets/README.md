# QR สำหรับสาธิต

วางรูป QR บัญชีทดสอบชื่อ `payment_qr.png` ในโฟลเดอร์นี้
ไฟล์รูปส่วนตัวไม่รวมใน Git หากไม่มีรูป แอปจะแสดง QR จำลองและให้แจ้งชำระเพื่อสาธิตได้

หน้านี้ใช้สาธิตการแจ้งชำระเท่านั้น ไม่ตรวจเงินเข้า ไม่แนบสลิป และไม่ยืนยันว่าชำระสำเร็จ
ออเดอร์ใหม่ใช้สถานะ `awaiting_payment_review` เพื่อรอการตรวจสอบ ส่วนออเดอร์เก่าไม่เปลี่ยนสถานะ


## ภาพประกอบเมนู
ภาพสร้างด้วยเครื่องมือสร้างภาพ ไม่ใช่ภาพอาหารจริงจากร้าน แสดงป้ายภาพประกอบในแอป
- menu_photo_sheet.png: 6 ภาพแรก
- menu_rice.png, menu_noodles.png, menu_drinks.png, menu_salads.png: แผ่นละ 12 ภาพ เรียงซ้ายไปขวา บนลงล่าง
- ชื่อเมนูและตำแหน่งรูปอยู่ที่ Frontend/menu_images.py ใน PHOTO_SHEETS
- ครอบคลุม 50 ชื่อเมนูที่เปิดขาย ณ วันที่9พฤศจิกายน2026 และภาพเมนูข้าวราดแกง
- เมื่อเพิ่มเมนูจริงใหม่ ต้องเพิ่มรูปและชื่อในรายการจับคู่ด้วย ไม่มีการเดาภาพให้เมนูที่ไม่รู้จัก
- แอปเก็บภาพย่อที่โหลดแล้วในหน่วยความจำเพื่อลดการเปิดไฟล์ซ้ำ

แนวทาง prompt ที่ใช้: ภาพอาหารไทยสมจริง แสงธรรมชาติ พื้นหลังสีครีม มุมเฉียงจากด้านบน ตาราง3คอลัมน์4แถว ไม่มีข้อความหรือโลโก้ แต่ละช่องเป็นอาหารตามรายชื่อใน PHOTO_SHEETS ตามลำดับ (ช่อง None เป็นภาพสำรองที่ไม่ได้ใช้)
